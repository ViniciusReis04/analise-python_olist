# Análise de Vendas Olist - Python

Projeto desenvolvido para portfólio em Análise de Dados utilizando base de dados real da Olist.

### Sobre o projeto
Análise exploratória dos dados de e-commerce brasileiro, com foco em vendas, pedidos e comportamento do cliente.

### O que eu fiz
- Limpeza e tratamento de dados com Pandas
- Análise de pedidos e status de entrega
- Criação de gráficos e insights

### Tecnologias usadas
Python, Pandas, Matplotlib
